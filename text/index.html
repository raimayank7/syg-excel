Text functions

TEXT function in Excel

TEXT turns a number or date into text in the format you choose.

A cell's number format changes how a value looks while keeping it a number. TEXT does something different: it produces a piece of text that looks the way you want. You need it whenever a number or date goes inside a sentence, a label or a joined code, because joining strips the formatting away.

Syntax

=TEXT(value, format_text)
ArgumentWhat it is
valueThe number or date to format.
format_textA format code in quotation marks, such as "0.00", "#,##0" or "dd-mmm-yyyy".

Examples

Each result below is what Excel itself showed for the formula on the sample sheet.

  • =TEXT(A2,"dd-mmm-yyyy")
    Result: 05-Jan-2026

    A date shown with a three-letter month.

  • =TEXT(A2,"dddd")
    Result: Monday

    The full name of the day of the week.

  • =TEXT(A2,"mmmm yyyy")
    Result: January 2026

    Month and year, the usual label for a monthly report.

  • =TEXT(F4,"#,##0.00")
    Result: 3,000.00

    A number with a thousands separator and two decimals.

  • =TEXT(F4/SUM(F2:F13),"0.0%")
    Result: 16.0%

    A share of the total shown as a percentage with one decimal.

  • =TEXT(E9,"000")
    Result: 003

    Leading zeros: 3 becomes 003.

  • ="Sale on "&TEXT(A2,"d mmm")&": Rs "&TEXT(F2,"#,##0")
    Result: Sale on 5 Jan: Rs 1,200

    The reason TEXT exists: a date and an amount inside a sentence.

  • =TEXT(A2,"yyyy-mm")
    Result: 2026-01

    A year-and-month key for grouping, such as 2026-01.

How it works

TEXT takes a value and a format code and returns the value written out in that format. The codes are the same ones used in Format Cells, under Custom, so any format you can build there can be given to TEXT.

Format codes for numbers

Code1234.5 becomesMeaning
"0"1235whole number
"0.00"1234.50two decimals, always shown
"#,##0"1,235thousands separator
"#,##0.00"1,234.50separator and two decimals
"0.0%"123450.0%percentage (the value is multiplied by 100)
"00000"01235padded with zeros to five digits

0 shows a digit always, with a zero if there is none. # shows a digit only when there is one.

The comma separator follows the international pattern, in groups of three. For the Indian pattern of lakhs and crores, a custom format such as "[>=10000000]##\,##\,##\,##0;[>=100000]##\,##\,##0;##,##0" is commonly used.

Combine them freely with spaces, dashes and slashes: "dd/mm/yyyy", "d mmmm yyyy", "ddd, d mmm".

The result is text

This is the point to remember. The output of TEXT cannot be added, averaged or compared as a number. =TEXT(A1,"0.00")+1 happens to work because Excel converts it back, but SUM over a column of TEXT results gives 0, and sorting them sorts as text, where "100" comes before "20".

So:

  • to change how a number looks in its own cell, use the cell's number format;
  • to round a number, use ROUND;
  • to put a number or date into text, use TEXT.

Useful patterns

  • A sentence: ="As on "&TEXT(TODAY(),"d mmmm yyyy").
  • Month labels for a summary: =TEXT(A2,"mmm-yy") turns each date into its month, which can then be counted or used as a heading.
  • Fixed-width codes: ="INV-"&TEXT(B2,"0000") gives INV-0042.
  • Day names: =TEXT(A2,"dddd").
  • Comparing a date with a text month: =TEXT(A2,"mmm")="Mar".

Regional settings

Date codes depend on the language of the computer. On a system set to German, the year code is j, not y. A workbook that uses TEXT with date codes may show odd results on a computer with different regional settings. Number codes are more portable, though the decimal and thousands characters also follow the system.

Common mistakes

  • Forgetting the quotation marks around the code.
  • Using mm for minutes on its own. After h it means minutes. Elsewhere it means month.
  • Adding up TEXT results.
  • Writing the code in capitals. "DD-MM-YYYY" works, but "MM" and "mm" are the same, so capitals do not separate months from minutes.

In Google Sheets

TEXT works the same way in Google Sheets, with the same codes for the common cases.
