Excel functions list

The 87 functions that cover everyday work in Excel, on 52 pages, grouped by what they are for. Type in the box to narrow the list by name or by job.

Lookup

  • VLOOKUPVLOOKUP finds a value in the first column of a table and returns a value from the same row in another column
  • HLOOKUPHLOOKUP finds a value in the top row of a table and returns a value from the same column in a row below
  • XLOOKUPXLOOKUP finds a value in one range and returns the matching value from another range, in any direction
  • INDEXINDEX returns the value at a given row and column position inside a range
  • MATCHMATCH returns the position of a value in a row or column
  • XMATCHXMATCH returns the position of a value in a range, with exact match as the default and a choice of search direction
  • CHOOSECHOOSE returns one value from a list that you type into the formula, picked by its position number

Logical

  • IFIF checks a condition and returns one value when it is true and another when it is false
  • IFSIFS checks several conditions in order and returns the result for the first one that is true
  • AND, OR and NOTAND is true when every condition is true, OR when at least one is true, and NOT reverses a condition
  • IFERROR and IFNAIFERROR returns a value you choose when a formula gives an error, and the formula's own result when it does not
  • SWITCHSWITCH compares one value with a list of possible values and returns the result that goes with the first match

Math

  • SUMSUM adds up numbers, cells and ranges
  • SUMIFSUMIF adds up the cells that meet one condition
  • SUMIFSSUMIFS adds up the cells that meet several conditions at once
  • SUMPRODUCTSUMPRODUCT multiplies ranges together item by item and adds up the results
  • ROUND, ROUNDUP, ROUNDDOWN and MROUNDROUND rounds a number to a chosen number of decimal places; ROUNDUP and ROUNDDOWN force the direction, and MROUND rounds to a multiple
  • INT and TRUNCINT rounds a number down to the whole number below it; TRUNC simply cuts off the decimals
  • MODMOD returns the remainder after one number is divided by another
  • SUBTOTALSUBTOTAL totals, counts or averages a list while ignoring rows hidden by a filter

Statistical

  • AVERAGE and MEDIANAVERAGE gives the arithmetic mean of a set of numbers; MEDIAN gives the middle value
  • AVERAGEIF and AVERAGEIFSAVERAGEIF averages the cells that meet one condition; AVERAGEIFS allows several conditions
  • COUNT, COUNTA and COUNTBLANKCOUNT counts cells that hold numbers, COUNTA counts cells that are not empty, and COUNTBLANK counts empty cells
  • COUNTIFCOUNTIF counts the cells in a range that meet one condition
  • COUNTIFSCOUNTIFS counts the rows that meet several conditions at once
  • MAX, MIN, MAXIFS and MINIFSMAX and MIN return the largest and smallest numbers in a range; MAXIFS and MINIFS do the same for the rows that meet conditions
  • LARGE and SMALLLARGE returns the nth largest value in a range and SMALL returns the nth smallest
  • RANK.EQ, RANK and RANK.AVGRANK.EQ gives the position of a number within a list, with equal numbers sharing the same rank

Text

  • LEFT and RIGHTLEFT returns characters from the start of a text and RIGHT returns characters from the end
  • MIDMID returns characters from the middle of a text, starting at a position you give
  • LENLEN returns the number of characters in a text, counting spaces
  • TRIM and CLEANTRIM removes extra spaces from a text, leaving single spaces between words; CLEAN removes characters that cannot be printed
  • UPPER, LOWER and PROPERUPPER changes text to capital letters, LOWER to small letters, and PROPER capitalises the first letter of each word
  • CONCAT, CONCATENATE and &CONCAT joins pieces of text into one; the & sign does the same between two values
  • TEXTJOINTEXTJOIN joins text from several cells or ranges with a separator between the items, and can skip empty cells
  • TEXTTEXT turns a number or date into text in the format you choose
  • SUBSTITUTE and REPLACESUBSTITUTE swaps one piece of text for another wherever it appears; REPLACE swaps characters at a given position
  • FIND and SEARCHFIND and SEARCH return the position of one piece of text inside another; FIND is case sensitive and SEARCH is not
  • VALUE and NUMBERVALUEVALUE turns text that looks like a number into a real number

Date and time

  • TODAY and NOWTODAY returns the current date and NOW returns the current date and time, both updating whenever the sheet recalculates
  • DATEDATE builds a date from a year, a month and a day given as three numbers
  • YEAR, MONTH and DAYYEAR, MONTH and DAY return the year, the month number and the day of the month of a date
  • WEEKDAYWEEKDAY returns the day of the week of a date as a number
  • EDATE and EOMONTHEDATE returns the date a number of months before or after a date; EOMONTH returns the last day of the month that many months away
  • DATEDIFDATEDIF returns the number of complete years, months or days between two dates
  • NETWORKDAYS and WORKDAYNETWORKDAYS counts the working days between two dates; WORKDAY returns the date a number of working days ahead

Dynamic arrays

  • FILTERFILTER returns the rows of a range that meet a condition, as a list that updates by itself
  • SORT and SORTBYSORT returns a range sorted by one of its columns; SORTBY sorts a range by the values of another range
  • UNIQUEUNIQUE returns the different values in a range, with each one listed once
  • SEQUENCESEQUENCE returns a list of numbers in order, such as 1 to 10, in rows and columns of your choosing

Financial

  • PMTPMT works out the fixed payment for a loan from the interest rate, the number of payments and the amount borrowed

Information

  • ISBLANK, ISNUMBER, ISTEXT and ISERRORThe IS functions test what kind of thing a cell holds and return TRUE or FALSE

How the categories are arranged

Lookup functions fetch a value from a table: the price for a code, the name for an ID. VLOOKUP is the classic, XLOOKUP the modern replacement, and INDEX with MATCH the pair that works in every version.

Logical functions make decisions. IF chooses between two results. IFS and SWITCH handle several. AND, OR and NOT combine conditions, and IFERROR deals with formulas that fail.

Math functions add, round and divide. The conditional adders SUMIF and SUMIFS are in this group, as is SUBTOTAL, which respects filters.

Statistical functions summarise a set of numbers: averages, counts, largest and smallest, and ranks. The COUNT family is here.

Text functions cut text into pieces, join pieces together, change case, remove spaces and convert between text and numbers. They are the tools for cleaning imported data.

Date and time functions work with dates: today's date, the parts of a date, the gap between two dates, month ends and working days.

Dynamic arrays are the functions introduced with Excel 2021 that return a whole list from one formula: FILTER, SORT, UNIQUE and SEQUENCE.

Financial and Information hold PMT, for loan instalments, and the IS functions that test what a cell contains.
