VLOOKUP or XLOOKUP: which should you use?

Excel now has two main lookup functions. VLOOKUP has been in every version for decades. XLOOKUP arrived with Excel 2021 and Microsoft 365 and was designed to fix VLOOKUP's weak points. This page puts them side by side on the same data, so that you can choose with your eyes open.

The same lookup, both ways

Find the price of the item with code C302.

  • =VLOOKUP("C302",A2:E8,4,FALSE)
    Result: 1299
  • =XLOOKUP("C302",A2:A8,D2:D8)
    Result: 1299

VLOOKUP is given the whole table and a column number. XLOOKUP is given the column to search and the column to answer from.

The default match

Leave off VLOOKUP's last argument and it does an approximate match. On an unsorted table that returns wrong answers without any warning. It is the best-known trap in Excel.

  • =VLOOKUP("B202",A2:E8,2)
    Result: Ball Pen
  • =VLOOKUP("B205",A2:E8,2)
    Result: Ball Pen
  • =XLOOKUP("B205",A2:A8,B2:B8)
    Result: #N/A

This table happens to be sorted by code, so the first formula is right. The second asks for B205, a code that does not exist, and VLOOKUP quietly returns the item for the nearest code below it. XLOOKUP, asked the same, reports that the code is missing.

Looking to the left

Find the code of the Notebook. The answer is to the left of the column being searched.

  • =XLOOKUP("Notebook",B2:B8,A2:A8)
    Result: B201
  • =INDEX(A2:A8,MATCH("Notebook",B2:B8,0))
    Result: B201

VLOOKUP cannot do this at all. Before XLOOKUP, the answer was INDEX and MATCH, shown in the second formula, which still works everywhere.

A value that is not found

  • =IFNA(VLOOKUP("Z999",A2:E8,2,FALSE),"Not found")
    Result: Not found
  • =XLOOKUP("Z999",A2:A8,B2:B8,"Not found")
    Result: Not found

Both give a message. XLOOKUP needs no wrapper.

Several answers at once

To bring back the item, category and price for a code, VLOOKUP needs three formulas with three column numbers. XLOOKUP takes a wider answer range and spills the results across.

  • =XLOOKUP("D401",A2:A8,B2:D8)
    Result:
    Steel BottleHome450

Bands and nearest matches

VLOOKUP's approximate mode needs the table sorted in rising order. XLOOKUP's match mode -1 (next smaller) and 1 (next larger) work on a table in any order.

  • =VLOOKUP(B4,$D$2:$E$6,2,TRUE)
    Result: B
  • =XLOOKUP(B4,$D$2:$D$6,$E$2:$E$6,,-1)
    Result: B

The last match

In a log kept in date order, the latest entry for a person is the last one. XLOOKUP can search from the bottom.

  • =VLOOKUP("Asha",B2:F13,5,FALSE)
    Result: 1200
  • =XLOOKUP("Asha",B2:B13,F2:F13,,0,-1)
    Result: 3750

VLOOKUP finds Asha's first sale. XLOOKUP, with its last argument set to -1, finds her most recent one.

So which should you use?

Use XLOOKUP when everyone who will open the workbook has Excel 2021 or Microsoft 365. It is safer by default, shorter and more capable.

Use VLOOKUP or INDEX and MATCH when the file may be opened in Excel 2019, 2016 or earlier. There, an XLOOKUP formula shows #NAME?, and the person receiving the file cannot fix it without rewriting it. In offices with mixed versions this is the deciding point. Check which versions your colleagues, clients and accountant use before changing over.

Keep reading VLOOKUP either way. Millions of existing workbooks use it, and you will meet it for years.

Turning a VLOOKUP into an XLOOKUP

Take =VLOOKUP(G2, $A$2:$E$8, 4, FALSE).

  1. The lookup value stays: G2.
  2. The search range is the first column of the old table: $A$2:$A$8.
  3. The answer range is the column that the number pointed to. Column 4 of a table starting at A is column D: $D$2:$D$8.
  4. Drop the FALSE. Exact match is the default.

Result: =XLOOKUP(G2, $A$2:$A$8, $D$2:$D$8).

If the old formula ended in TRUE or had no fourth argument, it was an approximate match. Add match mode -1: =XLOOKUP(G2, $A$2:$A$8, $D$2:$D$8, , -1).

Habits that help with both

  • Lock the ranges with dollar signs before copying the formula down.
  • Make sure both sides are the same type: numbers with numbers, text with text.
  • Clean stray spaces with TRIM.
  • Remember that both return the first match. For every match, use FILTER.
