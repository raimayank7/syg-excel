Excel formulas cheat sheet

The syntax of every function on this site on one page, with the basics of formulas at the top. Tap a function to open its page with worked examples. Arguments in square brackets are optional.

How to read this sheet

Each line in the function tables below shows a function the way Excel's own tip shows it while you type: the name, then its arguments in order, separated by commas. An argument in square brackets may be left out, and Excel then uses a default, which the function's page explains. Three dots mean you may add more of the same kind.

The words used for arguments are Excel's own, so they match what you see on screen. A few appear again and again. A range or array is a block of cells such as A2:A10. Criteria is a condition, written as in the conditions table below. A serial_number is a date, which Excel stores as a number. Text is a piece of text or a cell holding one.

The sheet is a reminder, not a lesson. If a line does not make sense, tap the function name. Its page shows the function at work on a small sample sheet, with results calculated in Excel.

If your Excel uses a semicolon between arguments, because of your regional settings, read every comma in these formulas as a semicolon.
