Logical functions

IF function in Excel

IF checks a condition and returns one value when it is true and another when it is false.

IF is how a spreadsheet makes a decision. It asks a yes-or-no question about your data and gives one answer for yes and another for no. Pass or fail, due or paid, reorder or in stock: almost every workbook that does more than add uses IF somewhere.

Syntax

=IF(logical_test, value_if_true, [value_if_false])
ArgumentWhat it is
logical_testA condition that is either true or false, such as C2>=33.
value_if_trueWhat to return when the condition is true.
value_if_falseWhat to return when it is false. If you leave it out, the result is FALSE.

Examples

Each result below is what Excel itself showed for the formula on the sample sheet.

  • =IF(C2>=33,"Pass","Fail")
    Result: Pass

    Asha has 78 in Maths, which is at least 33, so the result is Pass.

  • =IF(C5>=33,"Pass","Fail")
    Result: Pass

    Kabir has exactly 33. The test is "greater than or equal to", so he passes.

  • =IF(D6="","Absent",D6)
    Result: Absent

    Tara's Science mark is empty. The test for an empty cell is two quotation marks with nothing between them.

  • =IF(C2>=75,"Distinction",IF(C2>=33,"Pass","Fail"))
    Result: Distinction

    An IF inside an IF handles three outcomes. 78 is at least 75: Distinction.

  • =IF(C3>E3,"Better at Maths","Better at English or equal")
    Result: Better at English or equal

    The two sides of a comparison can both be cells. Ravi has 45 in Maths and 60 in English.

  • =IF(C2>=33,C2*1.1,0)
    Result: 85.8

    The results can be calculations: a 10 percent bonus on the marks if passed, otherwise 0.

How it works

IF has three parts, in the order you would say them: if this is true, then show this, otherwise show that.

The condition is a comparison, built with one of these signs.

SignMeaning
=equal to
<>not equal to
>greater than
<less than
>=greater than or equal to
<=less than or equal to

Text needs quotation marks

Text inside a formula goes in double quotation marks: "Pass". Numbers and cell references do not. =IF(C2>=33,Pass,Fail) gives the error #NAME?, because Excel takes Pass and Fail for names it has never heard of.

Comparing text ignores capital letters: "yes" equals "YES".

Showing nothing

To leave the cell looking empty when the condition fails, return two quotation marks: =IF(B2>0,B2*C2,""). Keep in mind that the cell then holds empty text, not a number, so a formula that later multiplies it may show #VALUE!. When the result feeds other sums, returning 0 is safer.

An IF inside an IF

For more than two outcomes, put a second IF in the place of the "otherwise". The fourth example gives three grades. Excel checks the conditions from left to right and stops at the first true one, so the order matters: test the highest boundary first.

Nesting two or three deep is fine. Beyond that the formula becomes hard to read and easy to break. Better choices for many bands:

  • IFS, which lists condition and result pairs without the brackets piling up;
  • a small table of boundaries with VLOOKUP or XLOOKUP in approximate mode, which is easier to change later.

Testing two things at once

IF takes one condition. To require two things together, or either of two, wrap them in AND or OR: =IF(AND(C2>=33,D2>=33),"Pass","Fail"). See AND, OR and NOT.

Common mistakes

  • Writing a range of numbers the way maths does. =IF(33<=C2<=100,...) does not work. Use AND(C2>=33,C2<=100).
  • Numbers in quotation marks. =IF(C2>=33,"1","0") returns text, which SUM ignores. Write 1 and 0 without the marks.
  • Comparing with text that has stray spaces. "Paid " with a space at the end does not equal "Paid".
  • Forgetting the third part. The cell then shows FALSE, which looks odd in a report.

In Google Sheets

IF works identically in Google Sheets.
