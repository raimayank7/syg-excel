INT and TRUNC functions in Excel

INT rounds a number down to the whole number below it; TRUNC simply cuts off the decimals.

INT and TRUNC both turn a number with decimals into a whole number without rounding to the nearest. Nothing is rounded up. For positive numbers they give the same answer. For negative numbers they differ, and that difference matters as soon as a sheet contains losses, refunds or temperatures below zero.

Syntax

=INT(number)
=TRUNC(number, [num_digits])
ArgumentWhat it is
numberThe number to cut down.
num_digitsFor TRUNC: how many decimal places to keep. 0 if left out.

Examples

Each result below is what Excel itself showed for the formula on the sample sheet.

  • =INT(F2/7)
    Result: 171

    1200 rupees shared among 7 people: each gets 171 whole rupees, and the fraction is dropped.

  • =INT(7.9)
    Result: 7

    The whole number below 7.9.

  • =INT(-7.9)
    Result: -8

    For negative numbers "down" means further from zero: -8, not -7.

  • =TRUNC(-7.9)
    Result: -7

    TRUNC just drops the decimals, so the answer is -7.

  • =TRUNC(1234.5678,2)
    Result: 1234.56

    TRUNC can keep some decimal places. Nothing is rounded.

  • =INT(E2/12)
    Result: 1

    20 units make one full dozen.

  • =E2-INT(E2/12)*12
    Result: 8

    And 8 units are left over. MOD does this in one step.

  • =A2+0.75-INT(A2+0.75)
    Result: 0.75

    INT removes the date from a date-and-time value, leaving the time as a fraction of a day: 0.75 is 6 in the evening.

The difference

  • INT goes down to the next whole number. On a number line, it always moves left. 7.9 becomes 7, and -7.9 becomes -8.
  • TRUNC chops off the decimal part. It always moves towards zero. 7.9 becomes 7, and -7.9 becomes -7.

If negative values are possible and you want "the whole-number part", TRUNC is usually what you mean.

TRUNC has a second argument for the number of decimal places to keep, so =TRUNC(3.14159,2) is 3.14. INT has no such option.

What INT is used for

Whole units and what is left over. How many full dozens, full boxes or full weeks? =INT(total/size) gives the complete units. The remainder is total - INT(total/size)*size, or more simply MOD.

Splitting hours and minutes. With 135 minutes in A1, =INT(A1/60) is 2 hours and =MOD(A1,60) is 15 minutes.

Separating a date from a time. Excel stores a date as a whole number of days and a time as a fraction of a day. A cell with both, such as 5 January at 6 pm, holds a number with a decimal part. =INT(A1) is the date alone, and =A1-INT(A1) is the time alone. This is the standard way to group time-stamped records by day.

Age in completed years from a number of days: =INT((today-birth)/365.25) is a rough method. DATEDIF is exact.

INT, ROUND or ROUNDDOWN?

Function7.97.2-7.9
INT(x)77-8
TRUNC(x)77-7
ROUNDDOWN(x,0)77-7
ROUND(x,0)87-8

ROUNDDOWN with 0 places and TRUNC behave alike. ROUND goes to the nearest. See ROUND.

A warning about tiny errors

Because of the way computers store decimals, a calculation that should give exactly 3 can come out as 2.9999999999. INT then returns 2. If a result that ought to be a whole number is going into INT, round it first: =INT(ROUND(A1/B1,6)).

Common mistakes

  • Using INT on negative numbers and being surprised by -8.
  • Using INT where rounding to the nearest was intended.
  • Expecting INT to change text. =INT("12 kg") gives #VALUE!.

In Google Sheets

INT and TRUNC are the same in Google Sheets.
